# Favela Sustentável

Projeto estratégico para transformar territórios urbanos vulneráveis com soluções integradas em água, educação, renda, saúde e governança comunitária.

## Visão
Criar um modelo replicável de desenvolvimento local com impacto social mensurável, sustentabilidade ambiental e gestão orientada por dados.

## O que foi melhorado nesta versão
- Estrutura do projeto reorganizada para leitura executiva e operacional.
- Diretrizes de implementação em fases com governança e indicadores.
- Nova experiência visual premium para apresentação pública em GitHub Pages.
- Publicação automatizada via GitHub Actions.

## Estrutura do projeto
- `/agua_meio_ambiente` — água, drenagem, reflorestamento e resiliência climática.
- `/educacao_tecnologia` — capacitação, conectividade e inovação comunitária.
- `/geracao_renda_politicas` — economia local, cooperativas e gestão participativa.
- `/implementacao_sustentabilidade` — cronograma, custos, monitoramento e escala.
- `/saude` — atenção primária, prevenção, teleatendimento e infraestrutura.

## Modelo lógico de execução
1. **Diagnóstico local**: mapeamento de riscos, ativos e prioridades.
2. **Planejamento integrado**: desenho de iniciativas por módulo.
3. **Implementação por ondas**: quick wins, expansão e consolidação.
4. **Monitoramento contínuo**: indicadores sociais, ambientais e econômicos.
5. **Escala territorial**: replicação com ajustes por comunidade.

## Indicadores estratégicos (exemplos)
- Redução de alagamentos e eventos críticos.
- Aumento de acesso a água tratada e energia limpa.
- Taxa de conclusão em programas educacionais.
- Geração de renda média por família participante.
- Cobertura de atenção preventiva em saúde.

## Site público (GitHub Pages)
A versão web está em `index.html` e usa `assets/` + `content/` para navegação dinâmica.

### Deploy automático
O workflow em `.github/workflows/deploy-pages.yml` publica automaticamente a branch padrão no GitHub Pages.

Para ativar no repositório:
1. Acesse **Settings > Pages**.
2. Em **Build and deployment**, selecione **GitHub Actions**.
3. Faça merge desta branch.
